# Finance OS

Public Obsidian starter system for a personal finance cockpit.

This repository intentionally contains **no private financial data**. It only contains structure, templates, CSS and example placeholders.

## What this is

Finance OS is an Obsidian-based personal finance cockpit with:

- Executive dashboard
- Asset and investment views
- Real estate and credit tracking
- Monthly reports
- Templates
- CSS-based KPI cards and navigation
- Dataview and Tasks queries

## Install

1. Copy `99 Finances/` into your Obsidian vault.
2. Copy `.obsidian/snippets/finance-os.css` into your vault-level `.obsidian/snippets/` folder.
3. In Obsidian, enable the snippet under `Settings → Appearance → CSS snippets → finance-os`.
4. Open `99 Finances/🏠 Dashboard/🏠 Dashboard.md`.
5. Create monthly reports from `99 Finances/⚙️ Templates/TPL Monatsreport.md`.

## Privacy rule

Do **not** commit real financial data to this repository.

Keep the following only in your local vault:

- real account balances
- bank names tied to real accounts
- account numbers or IBANs
- Kraken API keys
- financial documents
- screenshots
- CSV exports
- tax documents

The public repository is only the app shell: design, structure, templates and placeholder values.

## Workflow

Monthly minimum workflow:

1. Open Finanzguru.
2. Review categories, contracts and cashflow.
3. Create a local monthly report in Obsidian.
4. Enter the aggregated values only.
5. Let the dashboard summarize trends.
