# Installation

1. Copy `99 Finances` into your Obsidian vault.
2. Copy `.obsidian/snippets/finance-os.css` into the vault snippet folder.
3. Enable the snippet in Obsidian Appearance settings.
4. Open `99 Finances/🏠 Dashboard/🏠 Dashboard.md`.
5. Install Dataview and Tasks.

Do not push real values or documents to GitHub.
